GameSense 0.6.0 preview adds a native historical archive, source-aware athlete exploration, cached licensed portraits and interactive sport statistics. This work must be reviewed against the repository's newer existing public releases; it does not replace them automatically.

Download `GameSenseSetup-Windows.exe` for Windows or `GameSense-macOS.dmg` for macOS. Verify the corresponding SHA256SUMS file before installation. Data availability and statistical detail vary by provider and season; the app does not promise complete player archives for all sports.

These builds are unsigned. macOS builds are not notarised. Automated package checks exercise native startup; visible installation and all major screens still require target-machine review before publication. A successful build is not proof of complete historical coverage.

Release reviewer: inspect the build reports, package-check reports, provider terms and source attribution, then test on Windows and macOS without a developer environment before publishing this draft. This workflow never replaces existing release assets.
